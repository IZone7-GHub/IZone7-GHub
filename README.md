# Portafolio Técnico & Documentación

Bienvenido a mi repositorio centralizado de procedimientos, laboratorios y configuraciones. Este espacio recopila mi stack técnico, prácticas de sistemas, desarrollo backend y ciberseguridad.

---

## Arquitectura del Portafolio

* **`01_Sistemas_Operativos/`** 
  * Administración de sistemas Linux (Debian, Kali Linux), gestión de paquetes, permisos, scripts de terminal y automatización con Bash.
* **`02_Desarrollo_Web/`** 
  * Proyectos, apuntes y configuraciones en PHP, Laravel, JavaScript, C y servicios web.
* **`03_Bases_de_Datos/`** 
  * Modelado, consultas y administración de motores de bases de datos (MariaDB, MySQL, PostgreSQL, SQLite) y herramientas como PhpMyAdmin.
* **`04_DevOps_Contenedores/`** 
  * Despliegue y virtualización de entornos utilizando Docker.
* **`05_Ciberseguridad/`** 
  * Apuntes de laboratorios, prácticas de pentesting y ejercicios de seguridad ofensiva.
