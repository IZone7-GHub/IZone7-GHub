# Debian - Documentación y Procedimientos

Repositorio centralizado para la gestión, configuración y automatización de entornos en **Debian**.

## Estructura del Repositorio

* **`01_Sistemas_Operativos/`** - Configuraciones del sistema, administración y ajustes en Debian.
* **`02_Automatizacion/`** - Scripts y herramientas de automatización de tareas.
* **`03_Bases_de_Datos/`** - Procedimientos, consultas y esquemas de bases de datos.
